# Roadmap

## Public alpha

- Validate the portable contracts and synthetic examples with external readers.
- Improve error reporting and adapter conformance fixtures.
- Calibrate routing and behavioural evaluations against reviewed cases.
- Record ecosystem drift without silently changing the portable core.

## Public beta gate

- Test clean installation across the supported Python matrix.
- Stabilize schema and generated-bundle compatibility expectations.
- Add migration notes for breaking contract changes.
- Demonstrate held-out evaluation results across at least two independent hosts.

The roadmap is directional. It is not a release commitment.
