# Document summary

Use only the supplied document content.

1. Identify purpose, audience, and major claims.
2. Preserve qualifications and uncertainty.
3. Separate source-supported statements from inference.
4. Report missing content that could change the summary.
5. Produce a concise summary followed by `Unknowns` when needed.

Do not imply that summarization verifies the source's claims.
