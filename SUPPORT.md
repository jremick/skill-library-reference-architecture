# Support

Contributors who already have repository access may use GitHub issues for
reproducible bugs, documentation problems, and bounded architecture proposals.
Include synthetic examples and the exact validation command or error category
where possible.

This pre-public project does not provide general AI-agent support, vendor
product support, private configuration review, or guaranteed response times.
Do not report security issues in GitHub issues; follow the current pre-public
status and publication gate in [SECURITY.md](SECURITY.md).
