# Table analysis

1. Identify headers, units, row meaning, missing values, and type errors.
2. State the calculation before computing it.
3. Use deterministic calculation tools when available.
4. Report results with units and reproducible arithmetic.
5. Separate observed patterns from unsupported causal explanations.

Load [chart guidance](references/chart-guidance.md) only after activation and
only when the user explicitly requests a chart. Inspection alone does not meet
the load condition.
